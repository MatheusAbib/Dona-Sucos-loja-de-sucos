# 🍹 Dona Sucos

Site oficial da **Dona Sucos**, uma loja de sucos naturais, saudáveis e refrescantes.  
Projeto 100% front-end, feito com HTML, CSS e JavaScript puro — sem frameworks de build, sem back-end.

> 🔗 **Acesse online:** (https://matheusabib.github.io/Loja-de-Sucos/)

---

## ✨ Funcionalidades

- **Página inicial** com banner, carrossel de imagens e mensagem de boas-vindas
- **Seção Sobre** com texto institucional e imagem
- **Cardápio digital** com 5 sucos, preços e botão "Peça Agora"
- **Carrinho lateral (sidebar)** com:
  - Adição de produtos
  - Ajuste de quantidade (+ / −)
  - Remoção de itens
  - Cálculo automático do total
  - Envio do pedido com feedback visual
- **Botão flutuante de pedidos** com contador em tempo real
- **Campo de busca** em overlay (visual, sem busca real)
- **Formulário de contato** com validação de campos obrigatórios
- **Toasts** de feedback (sucesso e erro)
- **Scrollbar customizada** com a paleta do site
- **Menu responsivo** com hambúrguer animado (CSS puro)
- **Scroll suave** entre seções

## 🛠️ Tecnologias Utilizadas

| Ícone | Tecnologia | Descrição |
